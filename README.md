# Покемоны — фанатский сайт (SPA)

Русскоязычный фанатский сайт о покемонах: покедекс из 300 покемонов (полный национальный №1–300), описания характера, способностей и среды обитания. На главной — 10 самых популярных, весь покедекс — в выпадающем меню с поиском и на странице `#/dex` с фильтрами (тип, семейство, базовые формы, рост, вес). У каждой карточки — кнопка воспроизведения крика (`cries/`, Ogg Vorbis, настоящие крики покемонов). Полностью локальный (ванильный JS SPA, без сборки и зависимостей), работает оффлайн.

## Быстрый старт

Откройте `index.html` в браузере — сборка не нужна.

## Проверка JS

```bash
node --check js/data.js && node --check js/app.js
```
